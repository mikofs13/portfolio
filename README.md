# Michael Feleke Sahle — Studio portfolio

Next.js App Router, React, TypeScript, and custom responsive CSS. The project lives directly in this folder.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3000.

## Validate

```sh
npm run typecheck
npm run build
```

## Main files

- `app/page.tsx`: personal introduction, project content, experience, education, skills, and contact.
- `app/globals.css`: Studio design system and responsive layouts.
- `app/layout.tsx`: metadata and self-hosted Manrope font.
- `components/`: navigation, contact feedback, project layouts, and explanatory project diagrams.
- `public/studio-ribbon.webp`: optimized artwork generated with the built-in image tool.

The site uses supplied or previously confirmed personal details. Project artwork consists of explanatory illustrations, not production screenshots. Known GitHub and email destinations are used; repository URLs and achievements are not fabricated. Contact links open an email client. No contact form backend or visitor tracking is included.
